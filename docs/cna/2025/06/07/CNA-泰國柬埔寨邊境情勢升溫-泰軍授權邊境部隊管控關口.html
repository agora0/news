泰國柬埔寨邊境情勢升溫 泰軍授權邊境部隊管控關口

Jun 7, 2025

（中央社記者呂欣憓曼谷7日專電）泰國和柬埔寨的軍隊日前在邊境上的爭議區域交火，雙方尚未能達成解決共識，泰柬邊境情勢升溫。泰國陸軍司令今天授權陸軍的邊境部隊指揮官負責泰柬邊界各類型關口的開放與關閉事宜。

泰國和柬埔寨的軍人5月28日在泰柬邊境上的主權爭議區域發生衝突，造成1名柬埔寨士兵身亡。根據泰國皇家陸軍（Royal Thai Army）的聲明，是柬埔寨士兵在泰國東部烏汶省（Ubon Ratchathani）附近率先開火，泰國士兵對柬埔寨邊界部隊開火予以還擊，雙方交火約10分鐘後，柬方要求停火。

泰柬爭議邊界衝突交火 柬埔寨1士兵喪生

柬埔寨陸軍證實雙方「發生衝突」，但表示是泰國士兵攻擊在柬埔寨北部邊境和泰國接壤的普里維希省（Preah Vihear）執勤巡邏的柬埔寨部隊。

泰國主張泰方的行為屬於自衛行動，是為保衛國家主權所採取的必要措施，回應行動恰當、適度，並符合國際法。不過柬埔寨準備將泰柬雙方邊境有爭議的區域提交至國際法庭（ICJ）處理，泰國則希望透過現有雙邊機制與柬方進行談判。

雙方就此事未能達成協議，泰柬邊境情勢升溫，還有泰國民眾上街要求政府必須堅持捍衛主權，泰國媒體拍攝的影片和照片顯示邊境上的部隊整裝待發，學校老師開始帶著學生演練若有衝突如何就地找掩護。

泰國總理貝東塔（Paetongtarn Shinawatra）昨天召開國家安全委員會（National Security Council）會議，她表示軍方準備好捍衛泰國主權，同時了解局勢，明白何時需要採取升級行動。

泰國陸軍發言人溫泰（Winthai Suvaree）今天表示，陸軍司令帕納（Pana Claewplodtook）已簽署命令，授權布拉帕特遣部隊（Burapha Task Force）與蘇拉納瑞特遣部隊（Suranaree Task Force）的指揮官負責泰柬邊界各類型關口的開放與關閉事宜。

溫泰指出，帕納簽署的命令同時授權兩位指揮官，依據當地安全局勢與分級安全管控需求，制定合適的管理措施、標準、程序及必要條件。

溫泰表示，國家安全會議昨天的會議已指定泰國皇家陸軍為主要責任機構，負責監督與管理所有類型邊境關口的開放與關閉，以維護國家安全，並要求所有相關單位嚴格遵守皇家陸軍所制定的規定。

柬埔寨和泰國的邊界超過800公里，大多是在法國殖民中南半島時期劃定，長期以來雙方在邊界議題上一直爭執不休。（編輯：高照芬）1140607
