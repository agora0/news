三星推高階新機 估下半年手機市場延續量縮價升

Aug 28, 2026

（中央社記者江明晏台北28日電）三星今天在台推出Galaxy S26 FE新機，三星看好，手機市場持續朝高階化發展，600美元以上機種成為主要動能，今年上半年台灣整體手機市場銷售量下滑7%至8%，受高階化及記憶體漲價等因素帶動，銷售額反增3%至5%，預期下半年「量縮價升」趨勢將延續。

三星今天宣布在台推出Galaxy S26 FE，為首款搭載One UI 9的S26旗艦系列新機，將於9月4日開賣，電信通路由遠傳電信獨家上市，提供8GB、256GB容量版本，建議售價新台幣2萬5900元，瞄準中高階旗艦機市場。

三星說明，在One UI 9的加持下，Galaxy AI能自動順應使用者的日常習慣，提供最新資訊並排定事務，例如自訂天氣與健康洞察等資訊卡片，在一天當中適時提供貼合情境的建議。

台灣三星電子行動通訊事業部總經理陳啓蒙說明，今年上半年三星S系列銷售量年增10%，S26 Ultra比例占6成5，顯示消費者對旗艦手機市場需求高，600美元以上成為主要動能。

針對台灣整體手機市場，陳啟蒙說明，上半年銷售量約有7%到8%的下降，但銷售額有3%到5%成長，主因之一是記憶體漲價，還有市場朝高階化發展。

他預估，下半年記憶體的壓力還是在，AI需求是高的，意味著會帶動手機成本繼續增，下半年台灣市場銷售量大概還會有6%到8%的下降，但金額有望成長10%，整年度營業額可能會達到8%以上的正成長。（編輯：張均懋）1150828
