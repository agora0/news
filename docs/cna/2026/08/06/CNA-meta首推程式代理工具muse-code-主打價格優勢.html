Meta首推程式代理工具Muse Code 主打價格優勢

Aug 6, 2026

（中央社紐約5日綜合外電報導）Meta在旗下AI主管汪滔率領下，推出首款代理式程式設計工具Muse Code，試圖以「價格優勢」作為市場區隔，挑戰位居領先地位的Anthropic和OpenAI。

財經媒體CNBC報導，Meta去年高薪聘請Scale AI執行長汪滔（Alexandr Wang），成為Meta執行長祖克伯（Mark Zuckerberg）重振旗下企業AI策略的核心人物，他率領Meta超級智慧實驗室（Meta Superintelligence Labs）並監督基礎模型開發。

汪滔在專訪中表示：「只需一個指令就能安裝，然後可以用來處理各類用途的完整軟體工程任務，包括規劃變更、撰寫程式碼和驗證結果。」

隨Meta持續大舉投資資料中心和相關運算基礎設施，Muse Code是祖克伯試圖以AI帶來營收的另一種方式。Meta上週公布財報，由於營收展望遜於市場預期，且第2季自由現金流大幅下滑，股價因而重挫。

Muse Code就像Anthropic的Claude和OpenAI的Codex代理程式一樣，讓用戶能在單一介面中更輕鬆地開發應用程式，同時能管理AI數位代理群組，協助軟體開發流程。

Muse Code目前提供預覽版本，可搭配Meta最新的AI模型Muse Spark 1.2使用。汪滔拒絕透露Muse Spark AI模型的用戶統計數據，但表示「使用情況令人振奮且強勁」。

最新的Muse Spark模型與Muse Code共同開發訓練，汪滔指出，這有助提升整體程式碼編寫性能。

開發者使用Muse Code時，可按量計費。汪滔指出，Muse Code也設有「貢獻者方案」，比按量計費便宜10倍以上，但須「選擇同意協助改善模型」，讓Meta利用第3方數據來強化底層技術。

汪滔表示，相較Anthropic和OpenAI的熱門產品，Meta的Muse Code和Muse Spark不以技術比拚，而是以價格優勢作為市場區隔。

汪滔指出，Meta「也開始接受零數據保留（Zero-data retention）的請求」，代表他們不會藉開發者資料來改進模型，「這是對大家都很重要的重大企業級功能」。

不過，Meta多達98%營收來自線上廣告，而Meta正是透過用戶資料對消費者進行精準廣告投放，來主導這個市場。（編譯：張茗喧）1150806
