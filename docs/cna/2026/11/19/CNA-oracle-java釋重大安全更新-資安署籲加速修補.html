Oracle Java釋重大安全更新 資安署籲加速修補

Nov 19, 2026

（中央社記者趙敏雅台北19日電）美商甲骨文（Oracle）釋出緊急安全性更新，修補一項影響Java開發環境（JDK）的嚴重漏洞。數發部資安署今天表示，此軟體用於政府機關與企業網站及核心開發流程，攻擊者在未經身分驗證下即可取得系統主控權或導致服務中斷，呼籲機關及企業儘速完成版本比對並套用修補程式。

資安署發布新聞稿表示，甲骨文釋出緊急安全性更新，修補一項影響Java開發環境（JDK）的嚴重漏洞，編號為CVE-2026-114938，又稱Java4Shell，漏洞嚴重度評分（CVSS v4.0）高達9.2分。

資安署指出，這個軟體普遍用於政府機關與企業網站及核心開發流程，且廣泛應用於JSP、servlet等網站開發技術，攻擊者在未經身分驗證下即可取得系統主控權或導致服務中斷。

資安署表示，已於18日透過資安警訊與國家資安資訊分享與分析中心（N-ISAC）等聯防網絡，要求各級公務機關及關鍵基礎設施儘速完成版本更新或採取緩解措施，防範潛在入侵風險。

資安署提醒，更新或套用緩解措施後，也應檢視系統日誌、JVM（Java虛擬機器）異常重啟及對外連線紀錄，如發現可疑活動，應進一步確認相關帳號與憑證安全性。

資安署說明，甲骨文公布的Java開發環境（JDK）嚴重漏洞，問題出在JVM的Base64解碼器，攻擊者可利用特製輸入資料造成堆積記憶體（Heap）越界寫入，進一步竊取記憶體中的敏感資訊，甚至達成遠端程式碼執行（RCE），受影響產品OpenJDK 8u511b33-perf、17.0.21.0.3、21.0.13.0.3、25.0.5.0.3、27.0.1.0.3（含）以下的版本。

資安署強調，Java廣泛應用於網站及核心開發流程，各機關及企業應落實漏洞修補、最小權限原則與網路分段隔離，關閉非必要的外部連線暴露；更新完成後，務必持續監控系統日誌與異常連線紀錄，以全面防堵潛在滲透風險。（編輯：翟思嘉）1151119
