You're So Vain原唱卡莉賽門 證實罹患巴金森氏症

Jul 28, 2026

（中央社紐約27日綜合外電報導）經典名曲You're So Vain（自命不凡）原唱卡莉賽門（Carly Simon），今天透露自己罹患巴金森氏症。

法新社報導，這位83歲、以坦率描寫內心情感著稱的創作歌手在聲明中表示，她除了「在學習如何與巴金森氏症共處」，也已接受了皮膚癌治療。

巴金森氏症是一種慢性、退化性神經系統疾病，會影響身體的運動系統，常導致顫抖等動作困難。根據巴金森氏症基金會（Parkinson's Foundation）統計，全球約有1000萬人患病。

卡莉賽門在聲明寫道：「我花了一些時間才理解這個診斷結果，調適自我，並決定要在多大程度上對外公開。」

她說：「每個人的巴金森氏症狀況都不同，且難以預測。有些日子我根本提不起勁展開一天的生活，而有時病情比較和緩，讓我有機會活動、思考、創作，並感受到真正的自己。」

「這個問題從雙膝和單側髖關節關節炎開始，我最終將這3個關節全都換成人工關節。」經歷3場關節置換手術後，她補充說：「我原以為走路困難只是復健過程中不幸又帶點諷刺的部分。」

這位廣受肯定的創作歌手表示，自己在音樂中找到了慰藉，甚至在這段期間開始錄製新專輯Comes in Waves，這是她自2008年以來首度發表全新原創作品，預計於8月14日發行。

卡莉賽門表示，確診巴金森氏症的同時，她也接受了臉部基底細胞癌的治療。

她在聲明中說：「癌症已經切除，但手術影響了我的外貌，也讓我在公開場合更加在意自己的模樣。」

她說，她對自己外貌的要求，向來比旁人所能想像的要嚴格許多，並點出50多年前寫出You're So Vain這首歌是多麼的諷刺，如今又讓自我否定的「內在批評者」（inner critic）有了更多負面思考的素材。

卡莉賽門1960年代曾與胞姊一同演唱。1972年，她以專輯No Secrets一舉成名，其中收錄的單曲You're So Vain更攀上排行榜冠軍。

她1977年為007電影「海底城」（The Spy Who Loved Me）演唱的主題曲Nobody Does it Better，同樣也是歷久不衰的經典名曲；她更憑藉1988年電影「上班女郎」（Working Girl）主題曲Let the River Run，獲頒奧斯卡最佳歌曲獎。（編譯：蔡佳敏）1150728
