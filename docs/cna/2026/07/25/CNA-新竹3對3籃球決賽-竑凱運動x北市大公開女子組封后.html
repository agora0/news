新竹3對3籃球決賽 竑凱運動x北市大公開女子組封后

Jul 25, 2026

（中央社記者黎建忠台北25日電）「風城耀動、城市3耀」新竹城市盃3對3籃球賽，今天在市府前封路舉行首日決賽，其中公開女子組竑凱運動x北市大，靠著尹湘雲致勝跳投，以21比20擊敗All Rounded x Best封后。

由新竹市政府主辦的「風城耀動、城市3耀」3對3籃球賽，今、明2天在百年古蹟的新竹市政府前，封路搭建超過百萬元的籃球舞台舉辦。

今天的首日決賽，儘管下午有下起陣雨，但不影響比賽進行，其中公開女冠軍戰，由「竑凱運動x北市大」對上「All Rounded x Best」。

比賽開打後，竑凱運動x北市大靠著身高優勢，在籃下不斷取分，維持著領先優勢；All Rounded x Best則是靠著零星的中距離跳投，加上積極的切入禁區始終緊咬比分。

比賽剩下45秒，雙方戰成20比20平手，握有進攻權的竑凱運動x北市大，靠著身高僅153公分的尹湘雲，在時間剩下31秒時的急停中距離跳投得手，順利替球隊拿下封后的致勝分。

中華民國3對3協會理事長吳同喬賽後受訪時表示，第1天的決賽日就如此精彩，不論是大晴天或者下午的陣雨，選手們都還是認真拚戰，把最棒的球技呈現出來。

決賽首日公開女子組排名為冠軍「竑凱運動x北市大」、亞軍「All Rounded x Best」、季軍「北市大附小」；高中女子組冠軍「純情蟑螂火辣辣」、亞軍「我超辣」、季軍「禁區達陣」。

國中男子組冠軍「最後一舞」、亞軍「趴下掩護」、季軍「打球交朋友」；國中女子組冠軍「自強A」、亞軍「67戰隊」、季軍「你說主人喵喵」。（編輯：黃名璽）1150725
