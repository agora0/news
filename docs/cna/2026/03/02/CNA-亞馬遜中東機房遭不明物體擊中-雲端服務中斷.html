亞馬遜中東機房遭不明物體擊中 雲端服務中斷

Mar 2, 2026

（中央社阿布達比2日綜合外電報導）亞馬遜旗下的雲端運算部門今天表示，該公司位於中東的機房出現電力及連線問題，之前公司位於阿拉伯聯合大公國的一處資料中心遭不明「物體」擊中，引發火災。

路透社報導，亞馬遜公司（Amazon.com Inc.）雲端運算平台「亞馬遜網路服務」（Amazon Web Services,AWS）的阿聯和巴林區受到停電影響，這兩個區域都出現局部電力問題。

亞馬遜網路服務在其狀態頁面中公布，該公司在阿聯、巴林的2個雲端運算區域（即多個資料中心組成的叢集）今天皆出現斷電情況。

亞馬遜網路服務昨天表示，阿聯一座資料中心先前被「物體」擊中，產生火花並引發火災，電力隨即關閉。

對於外界稍早詢問，阿聯資料中心發生事故是否與伊朗為報復美國及以色列，對波斯灣鄰近國家（包括阿聯及巴林）發動襲擊有關，亞馬遜網路服務未予證實或否認。

亞馬遜雲端部門預期，阿聯與巴林地區要全面恢復服務仍需好幾小時。（譯者：高照芬/核稿：楊昭彥）1150302
