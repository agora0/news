台灣新車安全評等出爐 中華汽車CMC ZINGER 0顆星

Mar 30, 2026

（中央社記者余曉涵台北30日電）車輛安全審驗中心今天公布最新台灣新車安全評等（TNCAP），TESLA MODEL Y獲得5顆星評價，中華汽車CMC ZINGER獲得0顆星評等，且發現有座椅無法固定車體，將要求業者提改善措施。

交通部為提供消費者新車安全資訊，促使車輛產業升級，提升國內車輛安全性，推動台灣新車安全評等計畫（TNCAP），由財團法人車輛安全審驗中心執行。

車安中心今天舉辦記者會公布今年第1季的評等結果，車安中心執行長周維果表示，今年TNCAP進入第2版規範，較去年第1版來說標準跟要求更為嚴格，項目要求也加入在地化項目並貼近國際標準，在地化新增的項目包含盲點輔助系統試驗、電動車碰撞的觸電保護試驗項目等。

車安中心經理洪國益說，今年第1季評比的車輛為TESLA MODEL Y以及中華汽車CMC ZINGER，其中TESLA MODEL Y獲得5顆星評價，而CMC ZINGER則獲得0顆星評等。

洪國益指出，TESLA MODEL Y在4大安全領域得分中，成人保護93%、兒童保護89%、弱勢道路使用者保護75%及安全輔助71%，整體評等為5顆星。

CMC ZINGER在4大安全領域得分中，成人保護43%、兒童保護33%、弱勢道路使用者保護40%及安全輔助0%，整體評等為0顆星。

車安中心表示，CMC ZINGER車型在執行比強制性安全法規更嚴格的TNCAP前方偏置撞擊及前方全寬撞擊2項試驗後，都發現第2排座椅其一椅腳鎖扣脫開，造成座椅無法有效固定於車體。

車安中心指出，且CMC ZINGER車型在前方全寬撞擊試驗後，也發現第2排其1座椅安全帶脫開，造成乘客無法有效束縛的狀況，將請業者善盡企業責任，提出改善措施，並按照交通汽車安全性調查召回改正及監督管理辦法辦理召回改正。（編輯：林恕暉）1150330
