与澳洲签65亿美元合同 日本将首次出口军舰

Aug 5, 2025

德正
2025-08-05T11:24:21.016Z
升级版的“最上”级舰艇配备32个垂直发射单元，具备发射远程导弹的能力，航程可达1万海里，远高于现役澳新军团级护卫舰（Anzac Class frigates）的约6000海里

（德国之声中文网）日本周二（8月5日）与澳大利亚达成一项价值100亿澳元（约合65亿美元）的重要协议，将为澳海军建造新一代军舰。这是自2014年日本取消武器出口禁令、逐步摆脱战后和平主义以来，最重要的一笔国防军售。

“这是日澳两国史上最大规模的国防工业协议，也是日本有史以来最重大的防务出口项目之一，” 澳副总理兼国防部长理查德·马尔斯（Richard Marles）宣布交易时表示。

根据协议，三菱重工业将从2029年起向澳大利亚皇家海军提供升级版的“最上”级（Mogami-class）多用途护卫舰。

三菱击败德国蒂森克虏伯成功竞标

在澳政府国家安全委员会的评估中，日本的“最上”级战舰战胜了德国蒂森克虏伯的MEKO A-200护卫舰方案，成功竞标。

尽管德方主打成本更低、海外建造经验更丰富，但澳防务工业部长帕特·康罗伊（Pat Conroy）称，“最上”级舰艇在“成本、性能与交付进度”方面都是“明显的优胜者”。

马尔斯称，升级版的“最上”级舰艇配备32个垂直发射单元，具备发射远程导弹的能力，航程可达1万海里（1.6万公里），远高于现役澳新军团级护卫舰（Anzac Class frigates）的约6000海里。

这些战舰专为反潜、反舰及防空作战而设计，高度自动化，仅需约90名水手即可操作，人员需求不到现役舰艇的一半。

强化印太战略部署 应对中国影响力扩张

澳大利亚计划将这些新舰部署在印太地区，特别是其北部门户与关键海上贸易通道，以应对中国日益增强的区域军事存在。

“这将极大增强海军的远程投射能力，而有效的战略投射正是我们当前面临战略挑战的核心，” 马尔斯在记者会上表示。

对日本而言，这项交易是其拓展美日同盟以外安全关系的又一重要举措，意在抗衡中国在亚洲不断扩张的军事影响力。

“这将增强与澳大利亚及美国的联合作战与互操作能力，是日本防务合作的一大进展，”日本防卫大臣中谷元在东京表示。

美联社评论称，对三菱而言，这也是日本防务工业首次赢得海外建造海军舰艇的大项目。作为美国唯一的盟友，日本长期将澳大利亚视为“准盟友”，并积极深化双边军事合作，尤其是在有争议的南中国海局势持续紧张的背景下。

此次中标也弥补了日本在2016年失去澳大利亚潜艇合同的遗憾。当年澳方转而选择法国设计方案，后又于2023年取消该项目，改与美英合作建造核动力潜艇（即AUKUS协议 澳英美军事外交安全伙伴关系）。

三艘日本建造 八艘澳洲本土建造

该舰队将由11艘舰艇组成，用以替换现役的澳新军团级护卫舰队。首笔合同将订购三艘日本制造的护卫舰，预计首舰将于2030年投入使用。这将是澳大利亚自核潜艇协议签署以来最大的海军采购订单。其余八艘将由澳大利亚西澳州的奥斯塔尔公司负责建造。

三菱重工在新闻稿中表示，这一项目将“日澳两国工业界广泛参与通用护卫舰项目，将促进两国科技领域人才发展，强化国防工业基础。”

三菱重工和奥斯塔尔的股价在消息公布后分别上涨超3%与5%。

双方官员表示，关于价格、维护及生产转移至澳大利亚的具体安排仍需进一步谈判，预计将于明年初敲定正式合同。

（路透社 美联社）
