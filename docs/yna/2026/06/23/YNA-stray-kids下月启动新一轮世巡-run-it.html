Stray Kids下月启动新一轮世巡“RUN IT”

Jun 23, 2026

韩联社首尔6月23日电 经纪公司JYP娱乐23日表示，旗下男团Stray Kids将于下月启动新一轮世巡“RUN IT”。

Stray Kids将于7月25日、26日、29日和8月1日、2日在首尔奥林匹克公园KSPO巨蛋举行“RUN IT”首尔站演唱会后，8月转战日本，在东京新国立竞技场开唱。据介绍，Stray Kids将成为首个在此地举行专场演唱会的海外男性艺人。他们还将于9月在名古屋和大板、10月在福冈开唱。日本站演出共7场，有望吸引37万余人次观看。之后，他们将于12月在香港和台北，明年1月在曼谷，3月在新加坡开唱，后续举办地有待日后公布。

Stray Kids将于本月24日发布先行曲《RUN IT》，并于8月7日发布迷你专辑《THIS & THAT》。（完）
