全球收看BTS光化门演出…登顶奈飞77国榜首

Mar 23, 2026

2026-03-23 13:25  
▲ 21日，防弹少年团（BTS）正在首尔光化门广场举行新专辑发行纪念回归演出“BTS THE COMEBACK LIVE: ARIRANG”。/摄影联合采访团
据悉，韩国组合“防弹少年团（BTS）”的首尔光化门回归演出“BTS THE COMEBACK LIVE: ARIRANG”登上了77个国家的奈飞（Netflix）榜单榜首。

23日，据全球在线视频服务（OTT）排名统计网站FlixPatrol称，以22日为基准，“BTS THE COMEBACK LIVE: ARIRANG”在奈飞电影分类位列榜首。不仅韩国，美国、英国、加拿大、澳洲、奥地利、阿根廷、巴西、墨西哥、智利、法国、德国、意大利、西班牙、瑞士、香港、印度、日本、菲律宾、台湾、沙特阿拉伯等纳入统计的93个国家中，在足足77个国家登顶榜单。在此外的其他国家也全部进入前3名，足见其人气席卷全球。

值得一提的是该数据并未统计直播当时的观众数，仅按演出次日录播视频的播放数得出的结果。据悉，奈飞将于本周内公布直播的观看人数。

20日，防弹少年团发行了第5张正规专辑《ARIRANG》，距离2022年6月发行的精选专辑《Proof》，时隔3年零9个月再次推出完整体新作品。专辑发行次日（21日），成员们在首尔光化门广场举办演出，首次公开了主打曲《Swim》等新曲舞台。本次演出由“演出导演大师”哈密什·汉密尔顿操刀，他曾导演过艾美奖、格莱美奖、奥斯卡奖、美国超级杯中场秀等。

K-POP王者防弹少年团宣告回归，当地时间23日，他们将在美国纽约献上下一场演出。他们将联合音源平台Spotify举办特别活动“Spotify x BTS : SWIMSIDE”，与粉丝们见面。4月9~12日，他们还将以在京畿高阳综合运动场主体育场举行的单独演唱会为开端，开启世界巡演。
