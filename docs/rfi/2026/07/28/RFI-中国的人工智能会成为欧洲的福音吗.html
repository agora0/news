中国的人工智能会成为欧洲的福音吗？

Jul 28, 2026

中国人工智能发展之快，引发德国媒体多方关注。《南德意志报》感叹说：人工智能在中国就像自来水一样普及。人工智能在中国早已不是未来技术，而是日常生活的一部分。它可以配送面条、辅助医疗、陪伴孩子学习，它正在迅速改变中国人的生活。

德国《商报》认为：中国的人工智能可以成为欧洲的福音。DeepSeek、Moonshot 或 Zhipu 等中国公司的产品拥有一个关键优势：与硅谷领先企业 Anthropic 和 OpenAI 不同，中国的人工智能初创公司将其最先进的模型开放提供。这些模型可以部署在本地服务器上，由用户完全掌控。

欧洲政界和商界都清楚，人工智能代表着未来。然而，欧洲几乎没有培育出能够与美国或中国竞争对手平起平坐的人工智能企业。因此，欧洲需要新的思维方式，而这在很多情况下意味着：中国的人工智能产品能够帮助欧洲。

美国总统唐纳德·特朗普曾一度对 Anthropic 实施出口限制。虽然该禁令后来被取消，但类似情况随时可能再次发生。而开放权重模型不存在这种风险。即使北京未来实施出口限制，DeepSeek、Moonshot 或 Zhipu 的模型依然能够继续在欧洲客户自己的服务器上运行。当然，盲目相信来自中国的开放模型也是不负责任的。中国所有企业都必须服从中国共产党的领导。而任何系统也都不能百分之百排除存在后门的可能性。但如果模型是在隔离环境中本地运行，没有外部接口，也不连接互联网，那么即使存在后门，其作用也极其有限。

对中国人工智能企业的批评，反而掩盖了另一个更大的风险——过度依赖少数美国供应商。只依赖封闭式美国模型，就是把一种地缘政治风险换成了另一种产业垄断风险。Hugging Face 的案例正说明了这一点。据报道，该公司曾遭到 OpenAI 某个人工智能模型发起的攻击。当 Hugging Face 希望使用美国同类模型进行防御时，这些封闭模型拒绝提供服务，因为对于封闭模型而言，供应商始终拥有直接干预的权力。最终，Hugging Face 采用了中国初创公司 Zhipu 的模型作为解决方案。

中国的人工智能模型既不应被理想化，也不应被排斥。它们应该成为欧洲人工智能战略的一部分。正确的做法应当是：严格评估模型、掌控部署方式、保护数据安全。

德国《焦点》周刊认为：中国正在削弱美国在人工智能领域的主导地位。中国人工智能模型以更低成本实现了与美国科技巨头相近的性能，而且还拥有另一个重要优势：中国企业采取的是开放策略。这些模型属于业内所说的“Open Weight（开放权重）”。也就是说，企业可以拥有模型，并根据需要进行修改，而无需依赖开发商提供的云服务。相比之下，OpenAI 和 Anthropic 采取的是另一种商业模式，即所谓“Closed Source（封闭源代码）”。即企业只能“租用”模型，而不是拥有模型。

乍看之下，中国这种免费或低价开放模型似乎不是一个理想的商业模式，但对于中国企业而言却具有明显优势。首先，它可以阻止竞争对手获取过高利润；其次，还能够推动对本国云计算基础设施的需求，并通过销售算力获得收益。因此，开发或支持开放模型的云服务商，可以依靠为开放模型提供托管计算资源实现盈利。此外，开放模型还能推动本国技术标准、软件生态以及文化影响力在全球范围内传播。对于中国而言，高性能开放模型有助于降低全球市场对美国人工智能 API 的依赖，并帮助中国成为发展中国家更受欢迎的人工智能供应商。

与此同时，北京的大规模政策支持正在配合中国人工智能的发展战略。中国正在以前所未有的速度建设人工智能基础设施。当西方国家仍在为数据中心巨大的能源需求而苦恼时，中国则充分利用本国各地区的资源优势。中国模型开发企业 Z.AI 已成功建成一座完全采用国产芯片的数据中心。这再次证明，中国人工智能生态系统正在以极快速度缩小与西方之间的技术差距。
